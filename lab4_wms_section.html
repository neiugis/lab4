Add a WMS Layer

Every layer we have added so far has been one of two things: a tile layer, which is a set of pre-drawn map images, or a GeoJSON file, which you downloaded and saved into your own folder.

A WMS (Web Map Service) is a third kind. The server draws the map image at the moment you ask for it, using the area and the size you request. You do not download any data. You do not store any file. You send a request, and the server sends back a picture.

This matters because many government and research agencies publish their data this way and in no other way. If you want that data on your map, WMS is how you reach it. In this section we will add a layer from NASA.

  • Step 1. Choose a service. We will use NASA's Global Imagery Browse Services (GIBS), which publishes about one thousand satellite imagery layers. The same steps below work for any other agency service, such as the USGS National Map.
  • Step 2. Find the endpoint. The endpoint is the base web address of the service. NASA lists theirs on the GIS Usage page of the GIBS documentation. There are four, one for each map projection: 
    
https://gibs.earthdata.nasa.gov/wms/epsg4326/best/wms.cgi
https://gibs.earthdata.nasa.gov/wms/epsg3857/best/wms.cgi
https://gibs.earthdata.nasa.gov/wms/epsg3413/best/wms.cgi
https://gibs.earthdata.nasa.gov/wms/epsg3031/best/wms.cgi
    Look at the numbers. Those are EPSG codes, the same projection codes we discussed in class. 4326 is geographic latitude and longitude. 3857 is Web Mercator, which is the projection Leaflet draws in. We will use both, and the reason is in the next step.
  • Step 3. Browse the layers in QGIS. A service does not tell you its layer names from the web address alone. You have to ask it. QGIS is the easiest way to look.
    • Open QGIS. Go to Layer > Add Layer > Add WMS/WMTS Layer.
    • Click New. Give the connection a name such as NASA GIBS.
    • For the URL, paste the epsg4326 endpoint from Step 2. Click OK, then Connect.
    • You will now see the list of available layers, grouped into categories such as Land Cover and Sea Surface Temperature.
      Why the 4326 endpoint? NASA's documentation explains this. The 3857 endpoint returns the same layers as one flat list of over a thousand entries, which is very hard to read. The 4326 endpoint returns them grouped by category. We browse with 4326 because it is easier to read.
    • Pick a layer that interests you and click Add. Confirm that it actually draws on the QGIS map. If a layer looks empty, it may not have data for today's date. Choose a different one.
    • Write down the exact layer name. This is the one piece of information you need. It is case sensitive, and a single wrong character will produce a blank map later.
  • Step 4. Change the endpoint to 3857. When you move to Leaflet, change epsg4326 to epsg3857 in the web address. Everything else stays the same.
    This is a one character change, and it is worth understanding. You browsed in geographic coordinates because the list was easier to read. You request in Web Mercator because that is the projection your Leaflet map uses. Asking a service for the wrong projection is one of the most common reasons a web map layer does not line up.
  • Step 5. Add the layer to your map. Place the following AFTER your other layers. Replace PASTE_LAYER_NAME_HERE with the layer name you wrote down in Step 3. 
    
var nasa = L.tileLayer.wms('https://gibs.earthdata.nasa.gov/wms/epsg3857/best/wms.cgi?', {
    layers: 'PASTE_LAYER_NAME_HERE',
    format: 'image/png',
    transparent: true,
    opacity: 0.6,
    attribution: 'Imagery courtesy of NASA EOSDIS GIBS'
});
    • L.tileLayer.wms is the same kind of thing as L.tileLayer, with a few extra options. Notice that we assigned it to a variable, nasa, exactly as we did for the other layers.
    • layers is the layer name from Step 3. This is the option students most often get wrong.
    • transparent: true tells the server to leave the empty areas see through, so your other layers remain visible underneath. Try changing it to false to see the difference.
    • opacity controls how strongly the layer shows. A value between 0 and 1.
  • Step 6. Add it to the layers control. Add one line to your overlaymaps object: 
    
var overlaymaps = {
    "London Boroughs": boroughs,
    "NASA Imagery": nasa
};
    The WMS layer is an overlay, not a base layer, because it is data drawn on top of your map rather than the background your map sits on.
  • If the layer does not appear, check these four things in order:
    • Is the address https and not http? GitHub Pages will block http requests and will not warn you.
    • Is the layer name spelled exactly as it appeared in QGIS, including capital letters and underscores?
    • Does the address end with a question mark, as shown above?
    • Did the layer have data for the current date when you checked it in QGIS?
    Many NASA layers change from day to day. If you want a specific date, add a time option: 
    
    time: '2026-09-01'
  • Create a layer control with AT LEAST TWO basemaps (DIFFERENT from the ones I used in the example above; 6 pts) and TWO overlay layers in the same geographic area (different from the one I used; you may reuse your lab 3 data and find another one for the same region. 8 pts).
    • Feel free to reuse your lab 3 data as one of the overlay layers.
    • Your second layer does not have to be related to the theme of the map. It may be points, lines, or polygons (just for practice). You may leave the layer in the default style. If you would like to customize the layer, this Leaflet tutorial may be helpful.
    • Include ONE WMS layer as an additional overlay (5 pts). You may use the same NASA layer shown in the example above, or find a different one by following Steps 1 through 4. Either choice receives full credit.
    • Make sure to control the legend properly (3 pts).
    • Add a heading to your map to describe what you are mapping (3 pts).
